# Mufeed — Trusted School Reviews for Parents in Jordan

**مفيد | تجارب تساعدك تختار**

An independent, bilingual platform where parents in Jordan find schools, nurseries, kindergartens and online learning platforms, and read honest reviews from other families before choosing.

🔗 Live product: **[mufeed-edu.com](https://mufeed-edu.com)**

> This repository is a project showcase. It contains documentation only — the production source code is private.

---

## Overview

Choosing where a child spends their day is one of the hardest decisions a parent makes, and most of the information available is marketing copy. Mufeed collects the missing half: real experiences from parents, shared privately and published without names.

- **4,000+ educational facilities** across Jordan, in one searchable directory.
- **Anonymous reviews** — a reviewer's name and personal details are never published.
- **Human moderation** — every review is checked before it goes live.
- **Facility and admin dashboards** so institutions can respond and the team can moderate at scale.

## Key features

**For parents**
- Search facilities by name, location and category (nursery, school, kindergarten, digital learning platform).
- Facility profiles with the information that matters when comparing options.
- Reviews from real parents, published without the reviewer's identity.
- Bilingual interface (Arabic and English).

**For facilities**
- A dashboard to manage the facility profile and follow incoming reviews.

**For the platform team**
- A moderation queue so every review is reviewed by a human before publication.
- A full admin panel: facilities, categories, locations, reviews, and content management.
- Privacy-first review submission: a verified private contact is enough, no public account needed.
